## 📌 Overview

This repository contains the complete solution for **Session 25 (AIML) Assignment**. The assignment covers fundamental and advanced machine learning concepts including:
- **Manual Hyperparameter Tuning** (KNN, SVM)
- **Automated Hyperparameter Optimization** (`GridSearchCV`, `RandomizedSearchCV`)
- **Ensemble Learning Models**:
  - Bagging: `RandomForestClassifier`
  - Boosting: `AdaBoostClassifier`, `GradientBoostingClassifier`, `XGBClassifier`
- **Model Evaluation & Comparison**
- **Mini-Project & Deployment**: End-to-end pipeline creation, model serialization using `joblib`, and interactive web frontend using `Streamlit`.
